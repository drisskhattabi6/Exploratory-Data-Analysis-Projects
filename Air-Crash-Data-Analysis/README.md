# Air Crash Data Analysis

+ The main purpose of the analysis is to analyze the primary reason why an aircraft crashes,

+ By analyzing the data to find patterns and trends in accidents.

+ Several reasons, such as problems with the aircraft model, weather conditions, pilot error, etc.,

+ were analyzed. This will contribute to imposing additional restrictions, conducting pre-flight checks,
+ improving pilot training, and making technological modifications to aircraft.

+ The dataset used for the analysis comes from Kaggle and includes all accidents that occurred from 1908 to 2009.
